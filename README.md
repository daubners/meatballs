# meatballsss
Structure simulation solver for NMC particles (meatballs)


## Installation

Can be installed by cloning the repository

`git clone git@github.com:tldr-group/meatballsss.git`

and then locally installing in editable mode. Navigate to the meatballsss folder, then

`pip install -e .`

To utilize all plotting functionality in jupyter notebooks make sure to
```
pip install ipywidgets
pip install ipympl
```
