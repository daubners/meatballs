# meatballs
Structure simulation solver for NMC particles (meatballs)
Requires Python 3.9 or newer.


## Installation

Can be installed by cloning the repository

`git clone git@github.com:tldr-group/meatballs.git`

and then locally installing in editable mode. Navigate to the meatballs folder, then

`pip install -e .`

To utilize all plotting functionality in jupyter notebooks make sure to
```
pip install ipywidgets
pip install ipympl
```
